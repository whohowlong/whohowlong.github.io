# Haorong Hu · 学术主页

静态 GitHub Pages 站点。英文为首页，顶部可以切换中文。无须安装依赖，无须构建。

- `index.html`：英文首页
- `zh.html`：中文首页
- `style.css`：共用样式
- `assets/`：英文简历 PDF、站点图标和分享封面

双击 `index.html` 即可在本地预览。修改内容时请同步编辑两种语言。

## 部署到 GitHub Pages

1. 在 `whohowlong` 账号下创建 `whohowlong.github.io` 仓库（GitHub Free 使用公开仓库）。
2. 将本目录的文件上传到仓库根目录，包括隐含文件 `.nojekyll`；不要再套一层目录。
3. 打开仓库的 **Settings → Pages**，选择 **Deploy from a branch → main → / (root)** 并保存。
4. 部署成功后访问 [whohowlong.github.io](https://whohowlong.github.io/)。
